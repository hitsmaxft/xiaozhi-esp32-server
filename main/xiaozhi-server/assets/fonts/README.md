# RLCD monochrome icon font

`NotoEmoji-wght.ttf` is the monochrome Noto Emoji variable font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/notoemoji).
Downloaded from `ofl/notoemoji/NotoEmoji[wght].ttf` on 2026-10-05.
SHA-256: `de6c18832938afc99caf132b39d6a30a19bac7f2e812e28db2535b4608d27551`.

The font is distributed under the SIL Open Font License 1.1; see `OFL.txt`.
Only the local server rasterizes the font. ESP32 receives a bounded 1-bit frame.

`SymbolsNerdFontMono-Regular.ttf` and `nerd-glyphnames.json` come from
[Nerd Fonts v3.4.0](https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0).
Their SHA-256 digests are respectively
`f0f624d9b474bea1662cf7e862d44aebe1ae1f6c7f9cb7a0ca5d0e5ac9561c60`
and `e2d10d23f5bff0bd6f0676e9b01d9789fcdc656de7b498a2955c27716ea4439c`.
See `NERD-LICENSE.txt`. The local server uses the installed macOS SF font for
Latin titles when selected; no Apple font file is bundled.
